# လက်ကလေး — မြန်မာဗျည်းအက္ခရာ ရေးနည်း

မေမေနဲ့ ကလေးအတူ မြန်မာဗျည်း ၃၃ လုံးကို မြှားပြထားသော ပုံများကြည့်ပြီး ဖြည်းဖြည်း လေ့ကျင့်နိုင်သည့် .NET 10 Blazor WebAssembly app ဖြစ်ပါတယ်။

## ပါဝင်တာများ

- က မှ အ အထိ ဗျည်း ၃၃ လုံး
- အက္ခရာတစ်လုံးချင်းစီအတွက် ရေးသားပုံ
- ရေးသားပုံ၏ အနက်ရောင် အက္ခရာလမ်းကြောင်းအတွင်းမှာသာ လက်ညှိုး (touch)၊ စက်ဘောပင် (stylus) သို့မဟုတ် mouse ဖြင့် လိုက်ရေးနိုင်ခြင်း
- နောက်ဆုံးရေးထားသည့် မျဉ်းကို ပြန်ဖျက်ခြင်းနှင့် အားလုံးရှင်းခြင်း
- ရှေ့ / နောက် အက္ခရာ သွားရန် ခလုတ်များ
- လေ့ကျင့်ပြီးသော အက္ခရာများကို မှတ်ထားပေးခြင်း
- မေမေတို့အတွက် ရိုးရှင်းသော သင်ကြားနည်း ၃ ဆင့်
- ဖုန်း၊ တက်ဘလက်နှင့် ကွန်ပျူတာတို့တွင် အသုံးပြုနိုင်သော layout

## ဖွင့်နည်း

```powershell
dotnet run
```

Terminal တွင် ပြထားသော local address (ဥပမာ `http://localhost:5014`) ကို browser ဖြင့် ဖွင့်ပါ။

## နည်းပညာ

- .NET 10
- Blazor WebAssembly
- Pointer Events နှင့် Canvas ကို touch၊ stylus pen၊ mouse အားလုံးအတွက် အသုံးပြုထားပါတယ်။
- JavaScript ကို drawing canvas နှင့် browser ထဲတွင် progress သိမ်းရန် အသုံးပြုထားပါတယ်။
